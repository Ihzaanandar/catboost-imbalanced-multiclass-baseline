# GitHub upload checklist

1. Create a new public repository named `gemastik-catboost-baseline-portfolio`.
2. Extract the ZIP so these files are directly inside the repository root.
3. Commit and push the project folder contents.
4. Set the repository description to: `End-to-end CatBoost multiclass baseline with class weighting, stratified cross-validation, per-class evaluation, and reproducible outputs on a synthetic student tuition-fee dataset.`
5. Suggested topics: `machine-learning`, `catboost`, `classification`, `imbalanced-data`, `data-science`, `jupyter-notebook`, `python`.
6. Run the notebook locally before publishing a fully executed notebook. The included notebook is clean (no old output cells) so it can be run from scratch.
7. Dataset notice: keep the synthetic-data disclaimer visible in the README.
